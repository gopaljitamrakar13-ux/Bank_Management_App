🏦 Hogwarts Bank
🚀 Demo Bank Management System

Hogwarts Bank is a full-stack web application built as part of a learning project in modern web development.
It simulates real-world digital banking operations by integrating frontend, backend, APIs, and database systems.

⚠️ This is a demo / educational project and not a real banking platform.

🎯 Project Objective

The goal of this project was to understand how:

Frontend interfaces interact with backend systems
APIs handle requests and responses
Databases store and manage real-time data
A complete full-stack application is built from scratch

💻 Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
Database: PostgreSQL
Version Control: Git & GitHub

🚀 Features
👤 Authentication & User Management
User Registration & Secure Login System
Session-Based Authentication (Login / Logout)
Forgot Password Email Verification
Profile Update Functionality
Duplicate Email Detection

🏦 Banking Features
Automatic 12-Digit Account Number Generation
Account Balance Checking
Money Transfer Between Accounts
Transaction History (Sender & Receiver Details)
Credit History (Who Sent Money)

💰 Loan System
Loan Application (Instant approval up to ₹50,000)
Built-in Loan EMI Calculator

🎨 User Experience
Dashboard with Welcome Message & Account Details
Copy Account Number Button for easy sharing
Responsive UI (Desktop + Mobile)
Interactive Help Section
Form Validation (Email, Password, Phone)

⚡ Backend & Database
REST API-based backend using Flask
Real-time PostgreSQL database integration
Efficient data handling and query execution
